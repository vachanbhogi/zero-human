# Tack

Agent-run growth desk. Give us a URL — we come back with a campaign.

**Tack Sprint — $15.** Competitor teardown, personas, 10 outreach angles, one next move. Humans rate the copy on Terac.

Hackathon track: Zero Human. Rules live in `PROJECT.md`. Execution plan in `MVP.md`.

## Getting Started

```bash
npm install
npm run dev
```
